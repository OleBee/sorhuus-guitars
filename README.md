# Sörhuus Guitars

Exclusive, hand-built instruments from the atelier in Rælingen.

Live site: [https://olebee.github.io/sorhuus-guitars/](https://olebee.github.io/sorhuus-guitars/)

## Local

```bash
npm install
npm run dev
```

## Deploy

Push to `main`. GitHub Actions builds a static site and publishes it to GitHub Pages.
